# Noor

A personal web app for iPhone: prayer & iqama times, Qibla, tajweed Quran with audio, morning/evening adhkar, Ratib al-Haddad, dua for travel and a tasbih counter.

**Open:** https://shemiek.github.io/noor/ in Safari → Share → **Add to Home Screen**.

Works offline after the first visit (Quran audio streams from the internet). Settings, favourites and counts are stored only on the device.
